# Sobre mi : 

¡Bienvenido a mi GitHub! Me dedico a la **ciberseguridad ofensiva, el pentesting y la investigación de vulnerabilidades**. Suelo crear herramientas automatizadas para facilitar tareas de seguridad, auditar aplicaciones y sistemas, y resolver retos en entornos CTF y laboratorios.

En mi perfil encontrarás diferentes herramientas y proyectos enfocados en seguridad. No me hago responsable del mal uso que terceros puedan llegar a darle a alguna de las herramientas publicadas; todo el material tiene fines estrictamente educativos y de auditoría ética.
